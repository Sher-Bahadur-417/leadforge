# Leadforge

## Overview

**leadforge** is a full stack application built using **React and Express and TypeScript**.
**GitHub repo description:**  > AI-powered lead generation and qualification platform that finds, validates, scores, and organizes business leads for automated outreach.

## Features

- **Responsive Interface & Theming**: Modern utility CSS with responsive breakpoints.
- **Search & Filtering Functionality**: Detected search/filter components and controllers.
- **RESTful API Architecture**: Dedicated backend API route endpoints.
- **Interactive Data Dashboard**: Dashboard views and data visualization.

## Tech Stack

- **Frameworks & Core**: React, Express
- **Languages**: TypeScript, HTML5
- **Styling**: Tailwind CSS
- **Tooling & Environment**: Vite

## Project Structure

```text
src/                 # Main source code containing core business logic and modules.
components/          # Reusable UI components and visual elements.
package.json         # Node.js dependency manifest and run scripts.
```

## Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm, yarn, or pnpm package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Sher-Bahadur-417/leadforge.git

# Navigate into the project folder
cd leadforge

# Install dependencies
npm install
```

### Running the Project

```bash
npm run dev
```
